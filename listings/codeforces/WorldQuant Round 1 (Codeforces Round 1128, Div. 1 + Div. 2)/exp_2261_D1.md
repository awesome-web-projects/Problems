# 2261D1 — Come Be My Friend, Don't Be So Scared (Easy Version)

[Problem](https://codeforces.com/contest/2261/problem/D1) · [C++17 code](comp_2261_D1.cpp)

## Problem

There are `n` possible positions on a line. Each detector covers an interval and reports whether the hidden position lies in it. All reports arrive simultaneously. There are no existing detectors in D1 (`m = 0`). Output a minimum-size collection of intervals whose report vectors identify every position uniquely.

## Solution

If `n = 1`, output zero detectors. Otherwise set:

```text
k = (n + 1) / 2
```

Output `[i, i + k - 1]` for each `i` from 1 to `k`.

For `n = 5`, this gives `[1,3]`, `[2,4]`, `[3,5]`, with report vectors `100`, `110`, `111`, `011`, and `001`.

## Why it works

For a lower bound, sweep along the whole line, including the area outside all detectors. Each detector's bit changes exactly twice. With `k` detectors there are at most `2k` distinct report vectors because the two exterior regions have the same all-zero vector. For `n > 1`, distinguishing `n` positions therefore requires `k >= ceil(n/2)`.

In the construction, the first `k` positions acquire detectors one at a time. The following positions lose detectors in the same order. Reports within each phase are distinct; the first detector separates the two phases. If `n` is even, the final position has the unique all-zero report. Thus every position is distinguishable using exactly the lower bound.

## Complexity

- Time: `O(n)` per test case, proportional to the number of intervals printed.
- Extra space: `O(1)`.

## Execution tips and common mistakes

- Read both `n` and `m`, even though `m` is always zero.
- Handle `n = 1` separately; the general ceiling formula would unnecessarily output one detector.
- Use `(n + 1) / 2` for integer ceiling.
- The final interval ends at `2k - 1`, which is at most `n`; no clipping is needed.
- Print intervals directly instead of building report vectors or storing the answer.
- The number of detectors is linear in `n`, not logarithmic: interval restrictions prevent arbitrary binary encodings.

## Verification

The package checks report uniqueness for the construction for every `n` from 1 through 1,000. The lower-bound argument establishes optimality.
