# 2261F1 — Plegma II: Ask Me Any Cell (Easy Version)

[Problem](https://codeforces.com/contest/2261/problem/F1) · [C++17 code](comp_2261_F1.cpp)

## Problem and output format

A robot repeatedly deletes a top row (`U`), bottom row (`D`), left column (`L`), or right column (`R`). Its only input to each decision is the number `S` of ones in the 
current rectangle. One shared action table must locate every target cell when given that target's encoded binary grid.

Input is a single `n`, with no test-case count. Print `n^2` grids, in row-major target order, followed by the `n^2+1` action characters for signals `0..n^2`.

F1 uses `n=3, k=9` in the example and `n=20, k=24` in the main test, where `k` bounds zeros per grid.

## Construction used in this file

This submission uses the same three-zero construction as the accompanying F2 submission. Three zeros satisfy both F1 limits. Each file is standalone; neither includes the other.

For a rectangle of height `h`, width `w`, and `z` zeros, the signal is `S=h*w-z`. The zeros act as a mode that can only decrease as strips are deleted.

1. Reduce the height to three, using three zeros for `U` and two zeros for `D`.
2. Reduce the width to one while retaining the target column.
3. Use two final vertical moves to select one of the three remaining cells.

The shared table is:

```text
A[0] = A[1] = U; A[2] = D
For w = 2..n:
    A[3*w-3] = R
    A[3*w-2] = L
    A[3*w-1] = R
For h = 4..n:
    A[n*h-3] = U
    A[n*h-2] = D
All unused entries may be U.
```

The signal ranges for the final column, three-row stage, and taller rectangles do not overlap for `n >= 3`.

## Encoding a target

Set `up=min(r-1,n-3)` and `p=r-up`. Plan `up` top deletions with three zeros and `n-3-up` bottom deletions with two. This leaves the target in row `p` of a three-row rectangle.

- For `p=1` or `p=2`, delete `c-1` left columns with two zeros and `n-c` right columns with one zero. Finish with `D,D` for `p=1`, or `D,U` for `p=2`.
- For `p=3`, delete `n-c` right columns with three zeros and `c-1` left columns with two. Finish with `U,U`, using two zeros before the first move and one before the second.

To realize the planned counts, start with an all-ones grid. At a step where the zero count must fall by `d`, place `d` zeros in the strip that step removes. Deleted strips are disjoint. For `p=2`, one zero survives in the target cell; otherwise the target is one.

The zero-count schedule is non-increasing and starts with at most three, so the budget holds. The action table gives exactly the planned route, retaining the target after every deletion.

## Complexity and execution tips

- Time: `O(n^4)`, matching `n^2` grids of `n^2` cells each.
- Space: `O(n^2)` by printing and discarding one grid at a time.
- Do not store all grids or print explanatory labels to standard output.
- Use `'\n'` instead of `endl`; the main test prints substantial output.
- Include all `n^2+1` action characters, including the entry for `S=0`.
- Targets and grids must be printed in row-major order.
- Do not stop the first stage at one row; signal values for different modes would collide. Three rows keep them separated.

## Verification and further detail

The construction was simulated for every target at `n=3` and `n=20`, as part of all 21,864 targets across the sizes allowed by F2. Every grid uses at most three zeros.
